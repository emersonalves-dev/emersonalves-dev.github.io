AutoVideo Pro

AutoVideo Pro is a personal tool. Its owner uses it to upload and manage videos on the owner's own YouTube channels.

The tool uses the YouTube Data API to:

  • upload videos as private, set thumbnails, captions and translated titles and descriptions;
  • schedule publication and organize playlists;
  • read and reply to comments on the owner's own videos.

It is not offered to the public, and it does not access any account except the owner's.
