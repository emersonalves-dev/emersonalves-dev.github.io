Privacy Policy: AutoVideo Pro

Last updated: November 22, 2026

Who uses this app

AutoVideo Pro is a personal tool used only by its owner, on the owner's own Google account and YouTube channels. It is not offered to other users.

What data it accesses

With the owner's permission, granted through Google sign-in, the app uses the YouTube Data API to access the owner's own channels. That access covers:

  • basic channel information;
  • the owner's videos, thumbnails, captions, playlists and scheduling settings;
  • comments on the owner's own videos.

How the data is used

The data is used only to upload, update, schedule and organize the owner's own videos, and to reply to comments on them. The app does not sell, share or transfer this data to anyone. It does not use the data for advertising.

Storage

Authorization tokens and working records are stored only on the owner's computer. They are never published or sent to third parties. The owner can delete them at any time.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page.
